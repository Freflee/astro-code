# 第 1 周笔记

## 我今天用到的命令

| 命令 | 干什么 |
|---|---|
| `pwd` | 我现在在哪个目录 |
| `ls` | 这个目录里有什么 |
| `ls -lh` | 详细列表，文件大小看得懂 |
| `cd` | 切换目录 |
| `mkdir -p` | 建目录，父目录不存在就一起建 |
| `clear` | 清屏 |

## 我今天踩的坑

- `conda creat` 少打了一个 e，正确是 `conda create`
- `wsl -1 -v` 把字母 l 打成了数字 1
- `code.` 少了空格，正确是 `code .`
- `~/.condarc` 改了不生效，因为 conda 先读 `~/miniconda3/.condarc`
- 在 PowerShell 里敲了 Linux 命令 `whoami`
